# PoleOS
Arch Linux based opinionated setup for GNU/Linux

## Core components

* [Grab](https://wiki.archlinux.org/title/GRUB) -- boot loader.
* {{https://wiki.archlinux.org/title/Kernel|Main Arch Linux kernel}} -- a generic Linux kernel.
* {{https://wiki.archlinux.org/title/Systemd|SystemD}} -- suite of basic building blocks for a Linux system.
* {{https://wiki.archlinux.org/title/SDDM|SDDM}} -- display manager.
* {{https://wiki.archlinux.org/title/ACPI_modules|acpi}} -- The Advanced Configuration and Power Interface (ACPI) specification was developed to establish industry common interfaces enabling robust operating system (OS) directed motherboard device configuration and power management of both devices and entire systems.
* {{https://wiki.archlinux.org/title/Plymouth|Plymouth}} -- flicker-free graphical boot process.
* {{https://wiki.archlinux.org/title/Zsh|ZSH}} -- powerful shell that operates as both an interactive shell and as a scripting language interpreter.
* {{https://wiki.archlinux.org/title/Wayland|Wayland}} -- display server protocol.
* {{https://wiki.archlinux.org/title/PipeWire|Pipewire}} -- low-level multimedia framework.
* {{https://github.com/Jguer/yay|yay}} -- an AUR Helper Written in Go.
* {{https://wiki.archlinux.org/title/Flatpak|Flatpak}} -- system for building, distributing and running sandboxed desktop applications on Linux.
